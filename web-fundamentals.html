Web Fundamentals

  • World Wide Web (WWW) - A system of interlinked documents on the internet.
  • TCP/IP - Communication protocol used for transmitting data.
  • Web Browsers - Software like Chrome used to access websites.
  • Web Servers - Computers that store and deliver web pages.
  • HTTP - Protocol used to transfer web data.
